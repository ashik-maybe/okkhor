Okkhor — Bangla writing studio

Okkhor (অক্ষর) is a free, open-source Bangla writing studio for the browser. Type roman letters, get Bangla words. অক্ষর একটি বিনামূল্যের বাংলা লেখার স্টুডিও।

  • Avro Phonetic keyboard — the phonetic layout used by Avro Keyboard. Type “amar”, press Space, and “আমার” is committed.
  • Works offline — a Progressive Web App. Install it once; it never needs the network again.
  • Private and local-first — no accounts, no servers, no tracking. Your writing stays in your browser.
  • Free and open source — MIT license. Source on GitHub.

How it works

  1. Type roman letters — Okkhor uses Avro Phonetic, the same layout as Avro Keyboard.
  2. Pick a word from the suggestion list with the arrow keys, or press Space to accept the top choice.
  3. Keep writing — every word is saved on your device as you go.

Example: type amar, press Space, and আমার appears.

Frequently asked questions

What is Okkhor?

Okkhor is a free, offline Bangla writing studio for the browser. It converts roman (Latin) letters into Bangla words as you type, using the Avro Phonetic keyboard layout.

Does Okkhor work offline?

Yes. Okkhor is a Progressive Web App. After the first visit it installs like an app and works completely offline. Your writing is stored locally in your browser and never leaves your device.

Which keyboard does Okkhor use?

Okkhor uses Avro Phonetic, the same phonetic layout used by Avro Keyboard. Type “amar” and it offers “আমার”; press Space to commit the word.

Is Okkhor free?

Yes. Okkhor is free and open source under the MIT license. The source code is on GitHub.

Where is my writing stored?

Only in your browser, using local storage. Okkhor has no accounts and no servers; nothing you write is sent anywhere, and clearing your browser data removes the drafts.

Does Okkhor work on phones?

Yes. Okkhor is an installable Progressive Web App. On Android or iOS, use your browser's Add to Home Screen, and it runs offline with a touch-friendly candidate bar.

How do I install Okkhor?

Visit the site once, then choose Install app or Add to Home Screen in your browser. After that it opens like any other app and works without the network.
